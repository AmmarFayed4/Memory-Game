
**Memory Game** – A fun, interactive game built with HTML, CSS, and JavaScript, designed to test and improve memory retention. Players flip cards to find matching pairs, with smooth animations and intuitive gameplay.

**Key Features:**
- **Dynamic Card Matching Logic** – Implemented using JavaScript event handling.
- **Smooth Animations & Transitions** – Styled with CSS for an engaging user experience.
- **Responsive Design** – Works across different screen sizes for accessibility.
- **Score Tracking & Timer** – Enhances challenge and replayability.
